# Rajendra ♥ Monika — Premium React/Vite Wedding Invitation

This is the **React + Vite web project** — NOT Expo / React Native.

## Premium improvements

- Animated envelope opening with royal seal
- Rajasthani palace/mandap illustration used in the opening envelope and royal setting
- Falling floral/marigold particles
- Parallax movement on the hero and wedding caricatures
- Scroll-triggered fade/slide transitions
- Wedding music play/pause control
- Actual uploaded couple/family photographs in a dedicated real-memory gallery
- Full-screen photo lightbox
- Illustrated caricature cards for Lagan, Haldi & Mehendi, CHAK and Shubh Vivah
- Countdown to 1 December 2026, 9:00 PM
- Hindi/English toggle
- Welcome Resort + Google Maps
- WhatsApp RSVP
- Mobile-first royal maroon/gold design

## Run

```bash
npm install
npm run dev
```

Build production bundle:

```bash
npm run build
```

## Music

The existing `public/music/wedding-ambience.wav` is used by the music button. Replace it with your preferred wedding track if desired.

## Assets

- `public/images/` = illustrated/caricature wedding artwork
- `public/photos/` = actual uploaded photographs
